# Deploying Curtis Image Studio to Render

## One-time setup

1. Create a new Render account or log in at https://render.com
2. Create a new **Blueprint** from this repository (New → Blueprint → connect your repo)
3. Render reads `render.yaml` and creates two services automatically:
   - **curtis-image-studio** — the web service (Node API + React frontend)
   - **curtis-studio-keepalive** — cron job that pings `/api/healthz` every 14 minutes

## Environment variables to set manually in Render dashboard

After Blueprint creation, go to the **curtis-image-studio** web service → **Environment** and fill in:

| Variable | Description |
|----------|-------------|
| `PUBLIC_APP_URL` | The full HTTPS URL of your deployed web service, e.g. `https://curtis-image-studio.onrender.com` — required for Instagram publish and A2E video rendering |
| `AI_INTEGRATIONS_OPENAI_API_KEY` | OpenAI API key (from your Replit managed integration or OpenAI dashboard) |
| `AI_INTEGRATIONS_OPENAI_BASE_URL` | OpenAI base URL (e.g. `https://api.openai.com/v1`) |
| `A2E_API_KEY` | A2E image-to-video API key |
| `COMPOSIO_API_KEY` | Composio API key for Instagram publishing |
| `NVIDIA_API_KEY` | NVIDIA NIM API key — enables ultra-realistic cinematic prompt direction |

For the **curtis-studio-keepalive** cron service, set:

| Variable | Description |
|----------|-------------|
| `TARGET_URL` | Same as `PUBLIC_APP_URL` above, e.g. `https://curtis-image-studio.onrender.com` |

`SESSION_SECRET` is auto-generated by Render (`generateValue: true`).

## Port binding

The web service listens on port `10000` (Render's default). This is set via the `PORT` env var in `render.yaml`.

## Keep-alive cron job

The `curtis-studio-keepalive` cron job runs every 14 minutes and fetches `/api/healthz`.

- **On the free tier**: prevents the web service from sleeping after 15 minutes of inactivity.
- **On Starter and above**: the web service never sleeps — the cron job is harmless and simply logs a health check result.

## Re-deploying

Push to your connected Git branch. Render auto-deploys on every push.
